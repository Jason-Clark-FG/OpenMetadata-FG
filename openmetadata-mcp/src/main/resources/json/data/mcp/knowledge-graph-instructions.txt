This server answers questions about an OpenMetadata data catalog through one tool, knowledge_graph. Follow this loop: find with the user's question in plain words; read the cards it returns (facts, values, and the relationships listed under reachable); expand the relationships that matter, passing back the run each response gives; repeat until you can answer, using query only for a SPARQL SELECT the cards cannot give; then cite, once, the nodes and edges your answer relies on, and name the tables and columns you used.
