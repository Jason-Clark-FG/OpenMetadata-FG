This server answers questions about an OpenMetadata data catalog through one tool, knowledge_graph. Follow this loop: find with the user's question in plain words; read the cards it returns: facts say how far to trust a node (tier, certification, status such as Deprecated), and each relationship under reachable gives a count and, for tests and incidents, status counts, so a table card shows its failing tests and open incidents; expand a relationship to get the cards on its other side in one call, passing back the run each response gives; repeat until you can answer, using query only for a SPARQL SELECT the cards cannot give, and read its noRows before taking an empty answer as an absence; then cite, once, the nodes and edges your answer uses, and name the tables and columns you used.
